## About

Software architect based in Tokyo. At the core, what drives me is **designing systems** — the kind that govern how things work, whether that's a compiler, a distributed service, or a legal framework.

I write code in C, C++, Rust, and Python, and I think carefully about architecture. Lately I've also been studying law, drawn to the same underlying challenge: how do you write rules that are precise, unambiguous, and robust against edge cases? Turns out, it's not that different from writing software.

Outside of work, I play chess — another game about structure, foresight, and finding elegant moves under constraint.
